Academic Project Details

QR Code-Based Attendance Management System

Overview

A web-based attendance management application developed to reduce manual work and digitize the traditional attendance process. The system aims to simplify attendance recording, improve efficiency, and minimize errors associated with manual attendance management.

Core Objective

To make attendance tracking faster, more efficient, and easier to manage through a digital solution.

Architecture & Technologies

Python Flask HTML5 CSS3 JavaScript MySQL

Key Features

  • Dynamic student QR code generation with unique identification parameters.
  • Real-time QR scanning camera interface for rapid attendance logging.
  • Automated timestamp records preventing proxy attendance and duplicates.
  • Admin dashboard for managing student rosters and exporting attendance reports.
